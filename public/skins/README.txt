AutoDex - contours de skins (PNG)
Fichiers : bronze.png, argent.png, or.png, platine.png, diamant.png, arc-en-ciel.png, galaxy.png, godly.png.

Les images sont des découpes de la planche de référence. Elles sont destinées à être placées en superposition sur les fiches de voitures.
Important : le fond quadrillé de prévisualisation a été rendu transparent automatiquement. Vérifiez le rendu, en particulier les zones métalliques claires, car certains pixels gris très clairs peuvent être retirés.
Ces fichiers seuls n'activent pas les skins : il faut que le code du site les référence et applique la classe/skin correspondante.
